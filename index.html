Coursework

Laboratory Work

Lab 1

User Interface Fundamentals

In this lab, I built my first Android screen using Jetpack Compose, learning how to structure layouts with composables like Column, Row, and Box. It was my first hands-on experience creating a visually structured UI without XML. The exercise reinforced how declarative UI reduces boilerplate and improves readability.

Lab 2

User Interaction & State

This lab introduced state management in Compose using remember and mutableStateOf, allowing the UI to react dynamically to user input. I built interactive elements such as buttons, text fields, and counters. Understanding how state drives recomposition was a key insight that I carried into every subsequent lab.

Lab 3

Material Design 3

I applied Material Design 3 principles to polish the visual identity of my app, using components like TopAppBar, Card, FloatingActionButton, and a consistent colour scheme. This lab taught me how design systems accelerate development while ensuring accessibility. I saw firsthand how a coherent theme can transform a functional UI into a professional one.

Lab 4

Navigation Component

Lab 4 introduced multi-screen navigation using the Jetpack Navigation Component, enabling me to move data between screens via arguments and manage the back stack cleanly. I implemented a bottom navigation bar that tied multiple destinations together in a cohesive flow. This was the foundation for Project 1's full app structure.

Lab 5

Room Database Persistence

This lab walked me through setting up a local Room database with Entity, DAO, and Database classes, paired with a ViewModel and StateFlow for reactive UI updates. Persisting data across app sessions gave the app a sense of completeness it previously lacked. I also practised writing coroutine-based database operations to keep the main thread free.

Problem: People often struggle to discover and join local community events in their neighbourhood.

Building LepakJom taught me how to wire together navigation, state, and UI components into a complete, usable app. I encountered challenges managing navigation arguments across multiple screens but resolved them by structuring my NavGraph carefully. This project gave me confidence that I could deliver a polished product, not just isolated screens.
